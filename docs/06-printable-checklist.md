# Printable checklist

**AI Privacy Checklist** — Dated October 27, 2026
Published by Asdale Dynamics, LLC

Print this page and keep it by your computer. Check each item as you do it.

## My AI accounts

| ✅ | Task | App | Done |
|----|------|-----|------|
| ☐ | I listed every AI app I use | All | ☐ |
| ☐ | I checked what each app stores | All | ☐ |
| ☐ | I turned off training where available | ChatGPT, Claude, Gemini, Copilot, Perplexity, Meta AI, Grok | ☐ |
| ☐ | I know how to delete my history | All | ☐ |

## Opting out of training

| ✅ | Task | Where to find it | Done |
|----|------|------------------|------|
| ☐ | ChatGPT: "Improve the model for everyone" off | Settings → Data controls | ☐ |
| ☐ | Claude: "Train on my content" off | Settings → Data & privacy | ☐ |
| ☐ | Gemini: Gemini Apps Activity off or auto-delete | myactivity.google.com | ☐ |
| ☐ | Copilot: Copilot history off | account.microsoft.com/privacy | ☐ |
| ☐ | Perplexity: AI data retention off | Account settings → Data & privacy | ☐ |
| ☐ | Meta AI: training opt-out checked | In-app Meta AI settings | ☐ |
| ☐ | Grok: data sharing off | X Settings → Privacy | ☐ |

## Safe sharing habits

| ✅ | Task | Done |
|----|------|------|
| ☐ | No passwords, API keys, or secrets in AI chats | ☐ |
| ☐ | No Social Security numbers, IDs, or financial account numbers | ☐ |
| ☐ | No other people's names, addresses, or phone numbers | ☐ |
| ☐ | No patient health information in personal AI accounts | ☐ |
| ☐ | No company secrets, source code, or NDAs material | ☐ |
| ☐ | I remove names and details before asking sensitive questions | ☐ |
| ☐ | I use temporary chats for semi-sensitive topics | ☐ |

## If something goes wrong

| ✅ | Task | Done |
|----|------|------|
